Troubleshooting

If QR scanning is not working:

  • Admin Login: Make sure you're logged in as admin
  • Camera Permission: Allow camera access when prompted
  • Browser: Use Chrome, Firefox, or Edge (not Safari)
  • HTTPS: Make sure you're accessing via https://
  • Lighting: Ensure good lighting on QR code
  • Distance: Hold phone 10-20cm from QR code
  • Refresh: Reload page if scanner doesn't start
  • Camera: Close other apps using the camera
  • Valid QR: Use today's employee QR code only
